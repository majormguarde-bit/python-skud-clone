# СКУД Сервер

**СКУД Сервер** — это веб-приложение на основе Flask, предназначенное для управления системой контроля и управления доступом (СКУД). Оно предоставляет веб-интерфейс для мониторинга и настройки контроллеров, считывателей и других устройств системы.

## Технологии

*   **Бэкенд:** Python, Flask
*   **База данных:** Flask-SQLAlchemy (по умолчанию используется SQLite)
*   **Аутентификация:** Flask-Login
*   **Фронтенд:** Jinja2, Bootstrap

## Основные возможности

*   **Веб-интерфейс:** Удобный интерфейс для управления системой.
*   **Управление устройствами:** Добавление, настройка и мониторинг контроллеров, считывателей и конвертеров.
*   **Аутентификация:** Система пользователей с разделением прав (администраторы и обычные пользователи).
*   **Фоновые задачи:** Периодическое сканирование устройств для проверки их статуса.
*   **Логирование:** Ведение логов событий приложения.

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL репозитория>
    cd <папка проекта>
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Linux/macOS
    venv\Scripts\activate  # Для Windows
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Запустите приложение:**
    ```bash
    python run.py
    ```

    Приложение будет доступно по адресу `http://localhost:5000`.

## Учетные данные по умолчанию

При первом запуске создается пользователь-администратор со следующими данными:

*   **Логин:** `admin`
*   **Пароль:** `admin123`

## Структура проекта

*   `run.py`: Точка входа в приложение.
*   `app/`: Основной каталог приложения.
    *   `__init__.py`: Инициализация Flask-приложения.
    *   `models/`: Модели данных SQLAlchemy.
    *   `views/`: Представления (маршруты) Flask.
    *   `static/`: Статические файлы (CSS, JS, изображения).
    *   `templates/`: Шаблоны Jinja2.
*   `requirements.txt`: Список зависимостей Python.
*   `config.py`: Конфигурация приложения.
